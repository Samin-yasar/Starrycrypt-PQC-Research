Repository documentation

This folder contains the reference documentation for the release:

- `API.md` — JavaScript API reference for the WASM and pure-JS implementations.
- `ARCHITECTURE.md` — system architecture, design decisions, and component diagrams.
- `SECURITY.md` — threat model, assumptions, and recommended mitigations.
- `TESTING.md` — instructions for running unit, integration and statistical tests.

Usage

Read `API.md` for implementation details and `TESTING.md` to run verification and reproduce results. The docs are written for researchers and reviewers and are intentionally concise and reproducible.

If you want to convert these to HTML for hosting, use your preferred static site generator and point it to this folder.
